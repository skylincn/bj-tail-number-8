# beijing-moto-calendar（车牌 1068 定制版）

自动生成北京机动车尾号限行日历 `.ics` 文件，**已为你固定为尾号 8**（车牌 1068 最后一位 = 8，与尾号 3 同组限行）。订阅后把日历设为**红色**，到限行日一眼就能看到。

> 数据来源：北京市交管局官方页面 <https://jtgl.beijing.gov.cn/jgj/lszt/659722/660341/>
> 本仓库只按尾号轮换规则生成限行提醒，不判断具体禁行区域，也不区分车辆类型。北京限行不含周末与法定节假日，脚本已只生成工作日事件。

默认输出：

- 文件：`dist/plate-8.ics`
- 日历名称：`北京尾号8限行`
- 事件：`🚫 北京尾号8限行`
- 时间：限行日 `07:00–20:00`
- 时区：`Asia/Shanghai`

## 本地生成

需要 Node.js 20 或更新版本。

```bash
npm ci
npm run generate
```

生成后查看：

```bash
ls dist/plate-8.ics
```

## 如果以后换车 / 改尾号

默认尾号已固定为 `8`，也可用环境变量临时覆盖：

```bash
PLATE_TAIL=3 npm run generate
```

英文字母尾号会按北京规则作为 `0` 处理。

## iPhone / Apple 日历订阅（并设为红色）

复制下面的 raw 地址作为订阅 URL：

```text

```

> 这是只读订阅源，Apple 日历会定期自动刷新（频率由系统控制，通常每天）。

路径：**设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历**

（Mac 上也行：打开「日历」App → 文件 → 新建日历订阅 → 粘贴 URL。）

## 自动更新

GitHub Actions workflow 位于 `.github/workflows/generate.yml`：

- 每年 3、6、9、12 月的 20–28 日每天自动运行一次（北京每季度轮换一次尾号，脚本会自动抓取最新周期）。
- 支持手动触发 `workflow_dispatch`。
- push 到 `main` 时自动运行。
- 如果 `dist/plate-8.ics` 有变化，会自动提交并推送。

## 解析失败时的 fallback

生成器会优先抓取北京市交管局官方页面并解析限行周期。如果页面无法访问或解析失败，会使用内置 fallback 配置（已覆盖到 2027-03-28），尾号 8 的轮换为：

- `2026-06-29` 至 `2026-09-27`：尾号 8 周三限行
- `2026-09-28` 至 `2026-12-27`：尾号 8 周四限行
- `2026-12-28` 至 `2027-03-28`：尾号 8 周五限行

## 每日 6 点提醒（怕忘专用 · 快捷指令 + 提醒事项）

> 苹果日历订阅只能写入静态事件，做不到「弹出提醒、点了才消失」。要的是**交互式提醒**，用 iPhone 自带「快捷指令」自动化实现：每天 6:00 检查当天红色限行日历有没有事件，有就新建一条「提醒事项」，你不点「完成」它就一直挂着，直到你确认。

### 配置步骤（iPhone 上操作一次，之后全自动）

1. 打开 **快捷指令** App → 底部「自动化」→ 右上角 **+** → 「创建个人自动化」。
2. 触发条件选 **「特定时间」** → 设置为 **每天 06:00** → 下一步。
3. 添加动作，按顺序拼：
   - **「获取日期」**（今天，默认即可）
   - **「格式化的日期」**：把今天格式化为「日期」，用于查日程
   - **「获取日程」**（或「查找日历事件」）：
     - 日历：选你订阅的 **「北京尾号8限行」**（红色那个）
     - 时间：今天 00:00 – 23:59
   - **「如果」** `获取到的日程 的数量` **大于** `0`：
     - 在「如果」内添加 **「新建提醒事项」**：
       - 标题：`🚫 今天尾号8限行，1068 别开进城`
       - 列表：选你常用的（如「提醒事项」）
       - 勾选「提醒我」→ 时间设为今天 06:00（或留空，建好即提醒）
4. 关掉自动化顶部的 **「运行前询问」** 开关（否则每天会弹确认框，反而麻烦）。
5. 完成。

### 效果

- 每天 6:00 自动跑：若当天是尾号 8 限行日（日历里有红色事件），提醒事项里就多出一条。
- 你早上看到、点「完成」才消失；**没点就一直挂着**，绝不会漏看。
- 非限行日不会生成提醒，不骚扰。
- 限行星期每季度变化、节假日自动排除——这些判断**全部复用已订阅的红色日历**，快捷指令不用管，零维护。

## 为什么「远程一键建好个人自动化」做不到（含 C 方案实情）

Apple 的「个人自动化」（每天定时触发那种）**没有任何命令行/远程接口可创建**，任何人（人、Codex、还是其他 agent）都必须进快捷指令 App 在 UI 里点出来。`shortcuts` 命令只有 `run/list/view/sign`，没有 `import/create`；本仓库实测：**本机 `shortcuts sign` 无法把手工拼的 plist 签成能在 iPhone 打开的 `.shortcut` 文件**（Apple 私有签名格式，复刻不了）。

所以「完全不用你动一步」在 iOS 个人自动化上不成立——这不是权限或谁更强，是 Apple 的平台边界。能交付的两条路：

- **Mac 端全自动（已就绪）**：见 `每日提醒配置.md`。脚本 + `launchd` 写好并实测过，你本机终端跑一行 `launchctl load ~/Library/LaunchAgents/com.bjtailnumber.check.plist` 即生效。
- **iPhone 端（仍需你点 2 下）**：上面的第 5 章步骤。为减少你写逻辑，本仓库已备好 `scripts/limit_check_for_shortcuts.sh`（与 Mac 同判定逻辑），如果你在 iPhone 快捷指令里用「运行脚本」动作，可直接调用它，输出 `YES`/`NO` 供「如果」判断——省去拼日历查询那几步。

### 最短手机路径（2 下）
1. 快捷指令 → 自动化 → + → 创建个人自动化 → 特定时间：每天 06:00。
2. 添加动作 → 运行脚本（`scripts/limit_check_for_shortcuts.sh`）→ 如果输出 `YES` → 新建提醒事项（标题「🚫 今天尾号8限行，1068 别开进城」）。
3. 关掉「运行前询问」。

> 说明：`limit_check_for_shortcuts.sh` 需 iPhone 端有可运行 shell 的环境（如已配置 SSH/iSH 或 Mac 端接力）。若纯 iPhone 无 shell，则走第 5 章的「获取日程」方案即可，逻辑一致。
