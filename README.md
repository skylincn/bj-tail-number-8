# beijing-moto-calendar（车牌 1068 定制版）

自动生成北京机动车尾号限行日历 `.ics` 文件，**已为你固定为尾号 8**（车牌 1068 最后一位 = 8，与尾号 3 同组限行）。订阅后把日历设为橙色，到限行日一眼就能看到。

> 数据来源：北京市交管局官方页面 <https://jtgl.beijing.gov.cn/jgj/lszt/659722/660341/>
> 本仓库只按尾号轮换规则生成限行提醒，不判断具体禁行区域，也不区分车辆类型。北京限行不含周末与法定节假日，脚本已只生成工作日事件。

默认输出：

- 文件：`dist/plate-8.ics`
- 日历名称：`北京尾号8限行`
- 事件：`🚫 北京尾号8限行`
- 时间：限行日 `07:00–20:00`
- 时区：`Asia/Shanghai`

## 本地生成

需要 Node.js 20 或更新版本。

```bash
npm ci
npm run generate
```

生成后查看：

```bash
ls dist/plate-8.ics
```

## 如果以后换车 / 改尾号

默认尾号已固定为 `8`，也可用环境变量临时覆盖：

```bash
PLATE_TAIL=3 npm run generate
```

英文字母尾号会按北京规则作为 `0` 处理。

## iPhone / Apple 日历订阅（并设为橙色）

1. 将本仓库推送到你自己的 GitHub，确保 `dist/plate-8.ics` 已提交。
2. 复制 raw 文件地址作为订阅 URL，格式如下（把 `<username>` 换成你的账号名）：

```text
https://raw.githubusercontent.com/skylincn/bj-tail-number/main/dist/plate-8.ics
```

3. iPhone 上打开「设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历」，粘贴上面的 URL 并保存。

   （Mac 上也可：打开「日历」App → 文件 → 新建日历订阅 → 粘贴 URL。）

4. **设为橙色（核心需求）**：
   - iPhone：打开「日历」App → 底部「日历」标签 → 找到名为「北京尾号8限行」的订阅日历 → 点进去选一个**橙色**圆圈即可。
   - Mac：打开「日历」App → 左侧栏找到「北京尾号8限行」→ 右键「显示简介」或「偏好设置」→ 颜色选橙色。

   这样只有你车（尾号 8）的限行日会出现在橙色日历里，其余日子完全不显示，重点一眼可见。

Apple Calendar 会定期刷新订阅日历（频率由系统控制，通常每天）。

## 自动更新

GitHub Actions workflow 位于 `.github/workflows/generate.yml`：

- 每年 3、6、9、12 月的 20–28 日每天自动运行一次（北京每季度轮换一次尾号，脚本会自动抓取最新周期）。
- 支持手动触发 `workflow_dispatch`。
- push 到 `main` 时自动运行。
- 如果 `dist/plate-8.ics` 有变化，会自动提交并推送。

## 解析失败时的 fallback

生成器会优先抓取北京市交管局官方页面并解析限行周期。如果页面无法访问或解析失败，会使用内置 fallback 配置（已覆盖到 2027-03-28），尾号 8 的轮换为：

- `2026-06-29` 至 `2026-09-27`：尾号 8 周三限行
- `2026-09-28` 至 `2026-12-27`：尾号 8 周四限行
- `2026-12-28` 至 `2027-03-28`：尾号 8 周五限行
